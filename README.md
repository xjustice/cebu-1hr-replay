# Cebu 1-Hour Replay

Experience the beat of Cebu with a 1-hour continuous cinematic playback. Optimized for focus, relaxation, or virtual travel.

## Features
- **Premium Design**: Dark mode with glassmorphal UI elements.
- **YouTube IFrame API**: Seamless looping and state control.
- **1-Hour Timer**: Real-time countdown and progress bar.
- **Start Overlay**: Solves browser autoplay restrictions gracefully.
- **Responsive**: Desktop and mobile-ready.

## How to Host (GitHub Pages)
1. Push this repository to GitHub.
2. Go to **Settings > Pages** on your GitHub repository.
3. Select the `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://[username].github.io/cebu-1hr-replay/`.
